# Demo script

About five minutes. The thread is one sentence: **the agent does the work, but it can only spend what you
approved.** Say plainly which steps use real money and which are practice.

## Before recording

- Fund the buyer with a few dollars on Base (Home, Your buyer, add funds) and approve a spending session.
- Have one seller saved with a phone number you control, such as `+2348012345678`, if you will show a call.
- Use the account named in `PASSPORT_BUSINESS_ID`. Other accounts cannot pay.

## The run

1. **Landing page (30 seconds).** Scroll the 3D rack. "It finds, proves, compares, and then waits for my key
   before a cent can move." Try the limits section: fire a payment, then try to fool the gate.
2. **Setup (30 seconds).** Sign up. Point out that connecting a wallet is required, and why: it is where the
   buyer's money comes from, so every purchase traces back to you. Set a monthly limit.
3. **Research (60 seconds).** Ask for something small, such as a charger and label rolls under $20. Procura
   searches Amazon through Kite Passport. Searching is free and buys nothing. Open the comparison: three
   baskets, evidence per option, and the recommended one. Run "explain" to read the agent's reasoning.
4. **Confirm (30 seconds).** Pick an option, create the order, approve it. Show the fingerprint line: change
   one cent and the approval no longer matches.
5. **Pay (90 seconds).** Click Pay with Kite. Read out what it holds: the ceiling, the $1 fee, and that the
   unused part is refunded. Show the session from the passkey step. Confirm. Then check the order status.
   Say that this was real money, and how little.
6. **Call, if needed (60 seconds).** Open a seller with no website. Draft the call: it says it is an AI, only
   asks questions, never agrees to buy. Read the script, confirm, place the call, and show the summary.
7. **Close (15 seconds).** Limits page: "It can never raise these itself." Back to the sentence above.

## What to say honestly

- The Passport wallet here is production, so the purchase and the call were real, and small.
- Seller checks and the call run through Kite Passport and cost cents. Their replies are read defensively: an
  answer Procura cannot read is never recorded as verified.
- One Passport login serves one account today, so only one account can pay. Real multi-user use needs a
  per-user worker or an HTTP API from Kite.
- Practice checkout runs the full payment gate with no charge, and is useful to show the safety rules without
  spending.
